## Findings

### F1 Minor: the paragraph does not tell the owner which tab to open before downloading
Anchor: docs/guides/client-workflow.md:101-102
- **Scenario:** `scripts/intake-form.gs:104-105` creates the Sheet with its default empty tab, and linking the form adds "Form Responses 1" beside it. Review 01 N1 recorded this, and File, Download, CSV exports only the tab that is open. If the owner has the empty tab open (for example, after clicking it), he downloads an empty file.
- **Expected:** an instruction.
- **Actual:** "which gives the 'Form Responses 1' tab" reads as a guarantee. It is true on the first run only because that tab happened to be open.
- **Impact:** low. Claude would notice an empty CSV and ask again, which costs one round-trip.
- **Fix:** "with the 'Form Responses 1' tab open, File, Download, Comma-separated values ...".

### N1 Note: say "delete the row", not only remove it
Anchor: :107-108
"its row in the Sheet" could be read as clearing the cells. That leaves a blank row in `answers-NN.csv`, which is harmless but noisy. Optional fix: "(right-click the row number, Delete row)". The rest is correct and complete: delete in both places, the reason the Sheet keeps the row, and the timing (before the client answers). The Forms path (Responses, Individual, the bin icon) is the real control.

### N2 Note: the Envelope tree omits the form files
Anchor: :37-42
`intake/` in the tree lists `messages.md`, `documents/` and `facts.md`, but not `form-NN.gs` or `answers-NN.csv`, which section 2 and the glossary name. This predates this commit (it was the same at 40c3cd4). Optional fix: one line, `form-NN.gs, answers-NN.csv   Intake Form script copy and downloaded answers`.

### N3 Note: the date format and fonts depend on the setup
The M/D/YYYY dates follow the Sheet's locale (File, Settings), so another account could export D/M. The paragraph ties it to the first run, which is enough; Claude should not assume the format blindly on an ambiguous date like 3/4. Also, the brief says "Source Sans 3" was not found on the live page. The guide's fallback clause covers that, but the observation is recorded nowhere. It should go on the task card so the next themed form does not look like a regression.
