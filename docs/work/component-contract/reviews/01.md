## Disposition (author, 2026-09-25)

- **F1 fixed.** `lib.typ` exports the ctx-first components as two modules,
  `core-components` (`core/components.typ`) and `flagship-components`
  (`templates/flagship/components.typ`), so they cannot clash with the
  deprecated flat names or a later domain; a later template follows with
  `<template>-components`, in line with the naming rule on the docs-audit
  branch (`flagship` stays the template function). The constitution is
  unchanged. conventions.md states the one rule (entry points reach
  components only through `lib.typ`); AGENTS.md, architecture.md,
  skills-component.md and build-a-cv.md section 8 use it, with no deep
  component imports. Both documented snippets compile
  (`builds/doc-check/`). The one-line pointer in domains-and-roles.md's
  naming rule is added when main (with the docs-audit branch) is merged in,
  to avoid a conflicting edit now.
- **F2 fixed.** At the final head the private check keeps, under
  `builds/private-evidence-<stamp>/`: the script, a `tests/verify.py`
  exact-mode `result.json` per workspace, each `reference.pdf` SHA-256 and
  the HEAD commit id; the private copies are deleted afterwards. Path in the
  round-2 hand-off.
- **F3 fixed.** `section-heading` asserts only `spacing`; `number: none`
  renders the empty cell as before. The parity fixture calls the legacy
  wrapper with `none` (page 3).
- **F4 fixed.** `legacy-parity.typ` now calls all 32 wrappers, in both
  branches, over four pages; the suite reads `lib.typ`'s legacy export list
  and fails if any name is not called, and requires identical pixels on all
  four pages.
- **F5 fixed.** ADR 0008 is back to its accepted text plus one Status-line
  note ("Applied ... see `docs/history.md`"). The applied details moved to a
  2026-09-25 history entry with the counts corrected (32 components, four
  differing details); the earlier history paragraph no longer calls the
  migration "the next code task"; verification.md says 31 of 32 rendered
  alone, `document-shell` covered by the parity fixture.
- **N1 recorded.** framework-gaps.md "Style blocks not yet applied" (open)
  and a conventions.md bullet; history.md names it among the differences.
- **N2 addressed.** The round-2 hand-off and the card name the evidence
  folders per commit and at the final head.
