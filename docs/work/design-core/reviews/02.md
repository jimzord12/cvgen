## Findings

### R2-1 Minor: design reports in the `Envelope` have no defined place
Anchor: `.claude/skills/new-cv/SKILL.md:70-71`; `docs/guides/client-workflow.md:35-54`; glossary `Drawer`
The skill says "the `Envelope`'s `reviews/`", but the `Envelope` tree has no top-level `reviews/`. The only `reviews/` there is `research/reviews/<topic>-NN.md`, which holds research-reviewer reports. A lead could file design reports in either place, or collide with the research names.
Fix: add `reviews/design-NN.md` (or name `research/reviews/design-NN.md`) to the client-workflow tree and point new-cv at it.

### R2-2 Minor: N1 disposition only partly landed, because "concept" is still a synonym for `Style`
Anchor: `new-cv/SKILL.md:65` ("chosen concept folder") after `:59` ("picks a style"); `design-reviewer.md:36,64-66,115`; `idea-run/SKILL.md:118,124`; `design-concepts/README.md:26`; glossary `Style` row ("Earlier runs called it a concept")
The glossary makes "concept" historical, yet the new text uses it for a `Style` folder, a README row and a whole run. `Design Tier`'s row still says "each style" in lowercase. This is the same one-thing-two-words pattern that glossary Rule 1 targets.
Fix: either use `Style` in those lines, or change the row to say that "concept" names a `Style`'s folder and README row.

### R2-3 Minor: design-reviewer loose ends after the scope widening
Anchor: `design-reviewer.md:64-69, 94-100, 125-128`
- Criterion 7 has clauses for concepts and client designs but none for a Flagship change.
- Criterion 8 ("what it would take to become a template") is not excluded for a Flagship change.
- The return template still reads `Batch sheet: <path>` (singular) and `<run date>`, although there is now one sheet per page and client or asset reviews have no run date.

Fix: mark 7 and 8 n/a for Flagship changes, and make the fields `Batch sheets: <paths, or n/a>` and `<run date or subject>`.

### R2-4 Minor: design runs are now CV-only
Anchor: `magazine-editor.md:11-12, 49-68`; `idea-run/SKILL.md:17`; `design-concepts/README.md:31-33`
The last editor run (2026-09-27) produced `Text Draft` directions. The profile now requires nine CV pages that pass the `Batch Test` and `Three-Second Test`, and the design-reviewer's "For a concept page, all eight apply" contradicts its own "Other assets" section. A future run for a house-design or brand asset has no workable brief.
Fix: add one line to the editor and to idea-run: a run for a non-CV asset follows the lead's brief for its styles and tiers and is judged under "Other assets".

### N1 Note: vision.md never names `Flagship Parity`
review.md and the glossary row send the reader to vision "Design is the product" for the term. The bullet there is "The bar is the Marine Flagship". Naming it in that bullet would close the loop.

### N2 Note: real CV previews under `builds/`
`builds/design-review-input-<timestamp>/` holds real client pages outside `private/`, and the delete-by date does not reach them. There is precedent (build-a-cv.md:142; framework-split R1-N3). Suggest one clause: clear that folder by path when the loop ends.

### N3 Note: new-theme skill
`.claude/skills/new-theme` covers "a new look" and "a new role's illustrations", which is exactly where the `Three-Second Test` is won. A one-line pointer to vision would carry the core there too.
