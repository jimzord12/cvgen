## Findings

### R4-01 Minor: without jsonschema, the suite says an example record "breaks its schema"
Anchor: `tests/run.py:35-38`, `.claude/skills/verify-cv/SKILL.md:32-34`, `validate.py:64-67`.
- **Scenario:** a machine pulls main after the merge without the new dependency, then runs the suite.
- **Expected:** a dependency error.
- **Actual** (probe, import blocked in-process): `AssertionError: example record ../../candidates/captain-example.json (read by captain-silver.typ) breaks its schema: the candidate check needs jsonschema: pip install jsonschema`. For this prefix the skill says "Fix the record".
- **Impact:** low. The real cause is at the end of the line, and CI installs the pinned version. Still, this is the likeliest first failure after the merge, and it points at the wrong file.
- **Fix:** put `import jsonschema` at the top of `check_example_records`, so a missing package fails as `ModuleNotFoundError` before the loop. Alternatively, wrap only the mismatch error.

No real render reaches this today: no such domain exists, and the checklist requires a schema. Fix: "null when no imported template or domain has a schema and the lib.typ fallback does not apply".
