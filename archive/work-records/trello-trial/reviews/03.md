## Findings

### T3-01 Material: the failed request, with its Authorization header, stays in the caller's `$Error` and is printed by `Get-Error` or `$Error[0] | Format-List * -Force`
Anchor: `C:\Users\jimzord12\Documents\GitHub\marine-engineer-cv\.claude\skills\trello\trello.ps1:65-69` (catch block); SKILL.md:47-51 (which tells an agent that `2>&1` and `try/catch` see nothing, i.e. the next diagnostic step is `$Error`).
Scenario: any failed call (400/404/401/429, timeout) followed, in the same tool call, by PowerShell 7's standard "show me the real error" step: `& $T GET cards/<stale-id>; Get-Error` or `$Error[0] | fl * -Force`. `Invoke-RestMethod` sets the ErrorRecord's `TargetObject` to the `HttpRequestMessage`; its `ToString()` prints every header, including `Authorization: OAuth oauth_consumer_key="...", oauth_token="..."`. The catch exits the script but the record is already in the session's `$Error`.
Expected: SKILL.md "never prints them"; proposal line 33 "outside request logs". Actual (fake credentials, byte-identical HEAD copy): `fake\G-error-fl.txt` and `fake\G-get-error.txt` each contain the key and token once; the misconfigured-token FormatException path (`fake\I-badtoken-error-fl.txt`) also carries them in `Exception.Message`, unredacted.
Impact: same class as T2-01, one opt-in diagnostic away; `Get-Error` is a more common step than `-Debug`. Not exercised live.
Fix (one guarded line, first statement of the catch, before `$status`): `if ($Error.Count) { $Error.RemoveAt(0) }`. Verified on a scratchpad copy: `$Error.Count` is 0 after both failure kinds, `Get-Error` prints nothing, messages unchanged, exits 1/2/2 intact (`fake2\p2-*`). Removing only the header from `$_.TargetObject` covers the HTTP path but not the FormatException path (`fake2\p1-*`), so prefer `RemoveAt`.

### T3-03 Note: `$PSDefaultParameterValues['*:Debug'] = $true` fails safe non-interactively
The forced `-Debug` makes the cmdlet's verbose write prompt; under `-NonInteractive` (Claude Code's tool) and with null stdin it throws before the request is built, 0 hits (`fake\C*.txt`, `fake2\ni-psdefault-star.txt`).
