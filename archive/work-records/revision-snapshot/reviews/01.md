## Findings
### R1-M1 Material: comment stripping also removes URLs, hiding literal reads and the private/ refusal
Anchor: `packages/cv-workflow/cv_workflow/render.py:14`, used at `:32`
- **Scenario:** `//[^\n]*` also matches the `//` of a URL, whether in a string or in markup. Probe results:
  - `#link("https://instagram.com/ada")[#box(image("icons/instagram.svg", height: 8pt))]` → `[]`
  - `#link("https://x.org")[x] #let p = json("/private/client/presentation.json")` → `[]`, and no refusal.
  - A `/*` inside a string (`"docs/*"`) hides everything up to a later `*/`.
- **Expected:** literal reads are either copied or refused (the card's outcome; build-a-cv.md section 8 says "`render` finds these reads").
- **Actual:**
  - The icon is not copied, so the snapshot compile fails with "file not found". The docs say only a computed path can cause that.
  - The `/private/` read is not refused. It compiles against the live file, which gives a successful, approvable revision that depends on live data. That is the defect this card closes.
- **Impact:** a clickable link icon is a common CV idiom; that case fails loudly. The silent case needs a root-absolute private read after a URL on the same line. That is unlikely, but it is the exact mistake the refusal exists to catch.
- **Fix:**
  - Strip comments with a pattern that recognises strings and URLs, and put string matches back unchanged. For example: `"(?:\\.|[^"\\\n])*"|/\*.*?\*/|(?<!:)//[^\n]*`.
  - Add a line to ONE_OFF that reads a new file only after a URL.
  - A stronger, optional safety net: Typst 0.15.1 has `--deps`, and its JSON listed the example's json and SVG reads. Compile the snapshot with it, and fail the revision when any dependency is under the workspace or `private/` but outside the revision folder (paths come as `\\?\C:\...`). This also closes m2 and computed paths.

### R1-m1 Minor: prose `include "…"` in markup is taken for a file read
Anchor: `render.py:13`
- **Scenario:** `Signature tours include "Athens by Night"` is captured as `['Athens by Night']`.
- **Actual:** the render is refused with "cv.typ reads Athens by Night, which does not exist".
- **Impact:** a one-off design with quoted titles in markup cannot render until the text is rephrased. This could also newly refuse an existing composition.
- **Fix:** accept `import`/`include` only after `#`, `{`, `;` or at the start of a line.

### R1-m2 Minor: the private/ refusal is a plain string comparison
Anchor: `render.py:36`
- **Scenario:** `/./private/…`, `/packages/../private/…` and `/Private/…` are all accepted as repository files.
- **Evidence:** Typst reads all three spellings. I checked the same spellings on `builds/` (`/./builds/…`, `/Builds/…`, `/packages/../builds/…`); the compile exited 0.
- **Fix:** `(ROOT / target.lstrip('/')).resolve().is_relative_to(ROOT / 'private')`. This comparison is case-insensitive on Windows.
