## Findings

### M1 Minor: "Download responses (.csv)" delivers a ZIP file, not a CSV
Anchor: docs/guides/client-workflow.md:88-89
Scenario: the owner follows the guide and saves the download as `intake/answers-NN.csv`.
Expected: a CSV file.
Actual (my understanding of current Forms behaviour, not verified live here): this menu item downloads `<form title>.csv.zip`, with the CSV inside.
Impact: the owner may store a ZIP under a .csv name, or wonder which file to save.
Fix: add "unzip it; save the CSV inside as `intake/answers-NN.csv`", and confirm on the first run. Menu labels in a Greek Google UI will also differ; naming the three-dot (More) menu would help.

### M2 Minor: two places still describe the old shape
Anchor: docs/glossary.md:52; docs/guides/client-workflow.md:37
- The glossary row says "a per-client Apps Script", but everything else now says one copy per form.
- The `Envelope` tree describes `README.md` without the "Google" links that section 2 and the skill now require. A session setting up an `Envelope` from section 1 will not reserve that list.
Fix: glossary row "a per-form Apps Script"; add "Google links (form, Sheet, script project)" to the README line.

### N1 Note: the edit-link wording is right in substance but loose
Anchor: scripts/intake-form.gs:26-28; guide:86-87
Google shows the edit link only on the confirmation page after sending. It never comes back if the client closes that page, because the form collects no email and needs no sign-in.
- «στην τελευταία σελίδα» ("on the last page") can be read as the form's own last page. «στη σελίδα που βλέπεις μετά την αποστολή· κράτα τον σύνδεσμο» ("on the page you see after sending; keep the link") is clearer.
- The label «Επεξεργασία της απάντησής σας» follows the client's Google or browser language, so an English-set phone shows "Edit your response". I could not verify the Greek string; confirm it on the first run.

The guide's "only through the edit link" is accurate.

### N2 Note: "deleted" means Trash for 30 days
Deleting a file in Drive moves it to Trash, where it stays for 30 days unless emptied. The consent promise is met within that window. Optionally add "and empty the Trash" to the deletion sentence.

### N3 Note: the three-month dropout report does not name the Google items
Anchor: .claude/skills/new-client/SKILL.md:87-94
Only the post-`Export` report names the form, Sheet and project for deletion. Guide line 250 covers both cases, so this is a one-clause gap at most.
