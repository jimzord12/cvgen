## Findings

### F1 Material: an unreadable state file is silently replaced, which wipes every verdict and note
Anchor: `scripts/design_review/server.py:204-225`
- Scenario: `state.json` fails to parse. Causes include a hand edit with a trailing comma, a UTF-8 BOM added by an editor or PowerShell 5 `Set-Content`, or a future agent migration. AGENTS.md now points agents at this file.
- What happens: `load()` swallows the `ValueError` (including the BOM error) and returns `{}`. The board shows everything as unreviewed with no error. The next star or verdict click then calls `update()`, which writes a new file holding only that one entry.
- Expected: the file is never overwritten when it cannot be read, and the owner is told.
- Impact: silent, total and unrecoverable loss of the owner's review work. `.local/` is not in git.
- Smallest fix: `load()` returns `{}` only when the file is missing. On a parse error, raise, or move the bad file to `state.bad-<stamp>.json` before any write. Let `/api/items` surface the error.

### F2 Minor: keys pressed in Compare act on the hidden Loupe behind it
Anchor: `index.html:540-559`
- Scenario: in the Loupe, press T (twin compare), then press ←/→ or 1/2/3.
- What happens: `inLoupe` is still true, so the hidden Loupe steps or sets a verdict on its current item. That item may be the Condensed twin while the owner is looking at the Spacious one. Compare rows are not redrawn. Esc then closes both overlays, so the owner loses his place.
- Fix: when `#compare` is visible, handle only Escape, and make it close Compare alone.

### F3 Minor: no Host or Origin check (DNS rebinding and cross-site POST)
Anchor: `server.py:350, 378`
- Binding to 127.0.0.1 does not stop a web page in the owner's browser from reaching the app:
  - A DNS-rebinding page could read `/api/items` and `/api/page` renders of `private/` CVs.
  - Any site can send a text/plain POST to `/api/state` or `/api/open` for guessable ids.
- It is targeted and unlikely for a single-user tool, so I rated it Minor.
- Fix (a few lines): reject requests whose `Host` is not `127.0.0.1:<port>` or `localhost:<port>`, and require `Content-Type: application/json` on POST.

### F4 Minor: a date group that mixes the new layout with flat PDFs hides the flat ones on the Board
Anchor: `index.html:348-369`, `server.py:101`
- Groups are keyed by date only. If a run with Density folders and a flat `concept.pdf` folder share a date, the matrix branch finds no `density/tier` for the flat row and draws placeholders only. The label also comes from `gi[0]`.
- It does not happen with today's data.
- Fix: render non-matrix rows in the strip style inside matrix groups.

### F5 Minor: state is keyed by path, so moving files orphans reviews
Anchor: `server.py:236`
- The Density regroup (a801eb9) already moved files once. After a move, earlier verdicts and notes stay in the file but disappear from the Board and from the Markdown export.
- Fix: the export lists entries that are no longer indexed under their own heading.

### F6 Minor: after a rescan, the Loupe can jump to another item
Anchor: `index.html:439`
- `refreshLoupeList` keeps the old index after items before it are removed. The title changes to a different design while the notes field (if focused) keeps saving to the old one.
- Fix: re-find the current id rather than clamping the index.

### F7 Minor: the traversal test targets a file that does not exist
Anchor: `tests/design_review.py:104`
- `../secret.pdf` is missing, so a naive path-join implementation that 404s on missing files would pass.
- Fix: create a real, unindexed PDF (for example `repo/../secret.pdf` or `private/x/stray.pdf`) and assert 404. The `/api/open` test is strong: it asserts the opener was not called.

- `plain_pages` uses Typst from PATH, not `run.py --typst`.
- The plain pile is travel-market only, so it is the wrong market for marine CVs.
