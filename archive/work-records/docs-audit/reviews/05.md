Anchor: `docs/reference/domains-and-roles.md:129-135`

**Scenario:** this branch merges into `main` before `refactor/component-contract`. **Expected:** a reference doc describes the `lib.typ` in its own snapshot. That is the audit's stated aim (commit 52a5e36).
