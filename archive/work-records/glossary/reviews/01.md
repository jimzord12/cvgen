## Findings
### M1 Material: the owner's say over terms is missing from the one decision list
Anchor: docs/preferences.md:43-56; docs/glossary.md:20-22; AGENTS.md:204-207
Scenario: an agent wants to rename `Layout`. AGENTS.md:206 sends it to preferences.md as the *only* list of who decides what. That list says "Agents decide and do, without asking: … naming, structure, wording … Do not bring these to him".
Expected: acceptance item 4 says vocabulary is the owner's decision.
Actual: only glossary Rule 4 and one communication bullet (preferences.md:28-31) say he confirms terms. The authoritative list says the opposite.
Impact: an agent renames or promotes a term and only reports it afterwards.
Fix: add to "He decides": "official terms in `glossary.md`: making a candidate official, renaming or dropping a term". Narrow the agents' "naming" to code and file naming.

### M2 Material: the `Framework` row presents the unbuilt Framework/Domain split as today's code
Anchor: docs/glossary.md:30, 62; packages/cv-engine/lib.typ:8-29; AGENTS.md:4; docs/conventions.md:23
Scenario: the owner asks whether Travel & Tourism can use the `Framework` without marine. Row 30 says it "Knows no `Domain`", maps it to `core/` and `lib.typ`, and adds "docs also say 'engine'". So an agent answers yes.
Actual:
- `lib.typ` imports the marine domain (lines 8-9) and Flagship (lines 11-29), and entry points may only use `lib.typ` (conventions.md:23).
- The docs define "the engine" as "a field-neutral core plus domains" (AGENTS.md:4).
- Row 62 then proposes calling all of `packages/cv-engine`, which contains `domains/marine`, the `Framework`.

Impact: the code-name column is inaccurate, and the decoupling is described as done.
Fix:
- Row 30 code name: "`core/`; `lib.typ` re-exports it with marine and Flagship until the split is built".
- Row 30 synonyms: "docs say core; there 'engine' means the whole package".
- Row 62: propose `Framework` for `core/` only.
- Optional: the meaning's "fonts" and "checks" live outside `core/` (`fonts/`, `tests/`), so name those folders or drop the words.
