# Reference pairs

Before and after crops of one fictional CV design where the owner had to
ask for the after himself; he wants that finish delivered "without me
needing to ask" (owner, 2026-11-08). Each after is the finish every
CV design reaches before it is shown to him; each before is what fails
it. The `design-reviewer` judges criterion 6 ("Craft") against them, and
whoever designs a CV reads them first (`.claude/agents/magazine-editor.md`,
"Every page"; the `new-cv` skill).

## Rules

- Frozen. Never edit or replace a pair; a new lesson is a new pair.
- Fictional designs only: crops of concepts in `studio/design-concepts/`
  or of the `Release`, never a real `Client`'s page.
- Each pair is a folder `<date>-<subject>/` with `before.png` and
  `after.png`, the same crop of the same page at the same resolution,
  rendered from the two commits its row names. The first pair shows the
  bar at 150 dpi; every later pair is rendered at 300 dpi, the resolution
  reviewers judge criterion 6 at.
- PNGs only, so not part of the `Output Contract`: no PDF, no `Meta File`.
- Learn the principle, not the device: a pair teaches what finished looks
  like, never a motif to copy.
