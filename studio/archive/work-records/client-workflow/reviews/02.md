### F9 Minor: agent briefs must use the `Alias`, yet the Scout/Deep Dive brief names the `Envelope` path
Anchor: new-client SKILL.md:15-17, 71; guide:56-60
- Scenario: the lead briefs a Deep Dive author, which has web search.
- Expected: per the new rule, the brief contains only the alias.
- Actual: the brief must say "write only <absolute path to research/deep-dive-<topic>.md>". That path is `private/<name>-<rank>/…`, which is client data.
- Impact: the rule contradicts itself, and the name reaches an agent that can search the web. The brief's explicit ban on searching for the client limits this.
- Fix: the author returns its text and the lead saves the file. Or state that this path is the one allowed exception.

### F10 Minor: `Envelope` review reports named `research/reviews/NN.md` clash across Deep Dives
Anchor: SKILL.md:40; guide:46, 163
- Scenario: two Deep Dives each reach round 1, and both reports are named `01.md`.
- Impact: the second write silently overwrites the first, or the numbering leaves unclear which report belongs to which Deep Dive.
- Fix: name them `research/reviews/<topic>-NN.md`.

### F11 Minor: research-reviewer's new ban covers every person, cited authors included
